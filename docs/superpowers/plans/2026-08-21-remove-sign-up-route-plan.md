# Remove the Sign-up Route Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the public sign-up route and screen so `/sign-up` is no longer registered and resolves as not found.

**Architecture:** Delete the file-based route and its only screen component. Let TanStack Router regenerate the route tree from the remaining route files. Keep Better Auth configuration and development user provisioning unchanged.

**Tech Stack:** TanStack Start, TanStack Router, React, TypeScript, Vitest, Vite.

**Files:**

Create a compile-time regression test that asserts the generated route types no longer contain `/sign-up`:

```ts
import { describe, expect, test } from 'vitest'

import type { FileRouteTypes } from '../../routeTree.gen'

type SignUpRouteIsAbsent =
  Extract<FileRouteTypes['fullPaths'], '/sign-up'> extends never ? true : false

const signUpRouteIsAbsent: SignUpRouteIsAbsent = true

describe('sign-up removal', () => {
  test('does not register a sign-up route', () => {
    expect(signUpRouteIsAbsent).toBe(true)
  })
})
```
