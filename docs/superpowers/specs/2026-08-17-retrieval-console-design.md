# Retrieval Console UI

## Goal

Pantry を探す作業向けの一覧ファーストなコンソールにする。玄関グリッドはやめ、左はタグフィルタ、デフォルト表示は直した表、カード切替は残す。見た目は冷たいグレー地にくすんだティール1色。

関連: 置き換え対象の旧仕様は [2026-07-20-pantry-uiux-design.md](./2026-07-20-pantry-uiux-design.md)。画面コピーとデフォルト着陆は本仕様が優先する。

## Decisions

| 項目     | 決定                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| 着陸     | `/` は全件一覧。`view=entrance` は廃止。未知の `view` クエリは無視して一覧            |
| 左レール | 「すべて」とタグのフィルタ。ピンは上、ほかは `sort_order`。最終利用順では並べ替えない |
| ヘッダー | 検索（幅を取る）と新規。設定・タグ管理はレール（モバイルはシートとヘッダー）          |
| 一覧     | 表がデフォルト。カード切替は `localStorage` のまま                                    |
| 表       | 行全体が詳細への1ターゲット。タイトル列に URL を副次表示。タグと更新日時は列          |
| カード   | 行と同じ詳細へ。タイトル主、URL 副、メモ最大2行、タグ                                 |
| 色       | canvas/ink/line は冷たいグレー。accent は既存 `#2f6f6a`                               |
| コピー   | 玄関・箱・棚といった物置メタファーは画面から外す                                      |
| 範囲外   | 新機能、認証の変更、ダークモード、右プレビュー                                        |

## Information architecture

- ロゴはタグも `q` も付いていない全件一覧へ戻す。
- タグを1つ選ぶとそのタグで絞り込む。2つ目以降は一覧上のチップと「タグを追加」で足す。AND/OR は現行どおり。
- モバイルのシートは左レールと同じフィルタ。初面は一覧。
- `/tags` は裏方の表。`/bookmarks/new` と編集は作業台。詳細は1件。設定はアカウントとログアウト。
- ルート slug は変えない。

## List table

- 意味のある `<table>`。`<caption>` は視覚的に隠し、列は `<th scope="col">`。
- 列: タイトル（下に短縮 URL）、タグ、最終更新。
- 行は `position: relative`。タイトルのリンクを stretched link にし、行全体をクリック域にする。
- 行内の別操作（タグ管理の編集など）は `z-index` でリンクより手前。ブックマーク表に行内操作は置かない。
- URL は詳細と同じページへ重複リンクしない。文字列表示のみ。
- ホバーは行背景を `accent.hover`。フォーカスは stretched link の `:focus-visible`。
- `StyledLink` のデフォルト `size="md"`（高さ 3rem）は表セルで使わない。
- 狭い画面は横スクロールさせず、タイトル列で折り返す。タグは折り返してよい。

## Tag table

- 列: 名前（色ドットを名前の左に置く）、件数、ピン、操作。
- 名前のリンクはstretched で、そのタグの一覧へ。編集は手前の別リンク。
- ピンなしは `-` ではなく空（スクリーンリーダーには「ピンなし」）。

## Chrome

- 一覧に大きな「すべて」見出しは置かない。`<h1>` はスクリーンリーダー用に残す。
- AND/OR・並び・表/カードは一覧直上のコンパクトなコントロール。未選択は弱い枠、選択中だけティール。
- タッチターゲットは 44px を維持する。
- スキップリンクで `<main id="content">` へ飛ぶ。

## Tokens

| 役割        | 方針                                                                 |
| ----------- | -------------------------------------------------------------------- |
| canvas      | 冷たいグレー。暖灰 `#f7f6f3` は使わない                              |
| surface     | canvas よりわずかに明るいオフホワイト。純 `#fff` / `#000` は使わない |
| ink / muted | チャコール系                                                         |
| line        | 中間の冷灰。表の行区切りに使う                                       |
| accent      | `#2f6f6a` のみ。選択中フィルタ、主CTA、フォーカス                    |

角は既存 `box`（6px）。影は使わない。

## Copy

| 旧                                   | 新                                     |
| ------------------------------------ | -------------------------------------- |
| 玄関へ戻る                           | 一覧へ戻る                             |
| 棚を変える / 棚を選ぶ                | タグ / タグを選ぶ                      |
| まだ箱がありません                   | まだタグがありません                   |
| この棚はまだ空です                   | まだブックマークがありません           |
| 箱のラベル・ピン・色を整える裏方です | 名前・ピン・色を整えます               |
| 箱の名前を付け…                      | 名前を付け、必要ならピンと色も決めます |

## Five UI states

一覧・タグ管理・レールの Empty / Loading / Partial / Error は現行どおり。玄関面の状態は削除する。

## Accessibility

- 行・カード・フィルタはキーボードで到達できる。
- 表はキャプションと列ヘッダーを持つ。
- 同じ行に複数リンクがある場合、名前が衝突しない（編集は「{name}を編集」）。
- `prefers-reduced-motion` は既存グローバル打ち消しのまま。
