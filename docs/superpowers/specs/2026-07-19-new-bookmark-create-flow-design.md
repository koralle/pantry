# 新規ブックマーク登録フロー（導線）Design

## Goal

ブックマーク一覧画面から新規ブックマーク作成画面（`/bookmarks/new`）へ遷移する導線を追加する。ヘッダーに常設リンクを置き、一覧画面内にも目立つ導線を置く。作成画面から一覧へ戻るリンクを確認・整備する。作成画面のフォーム（中身）は変更しない。

## Background

MVP設計（`docs/superpowers/specs/2026-07-19-turso-rpc-mvp-design.md`）は「登録フォームでURLを入力し…」を想定しているが、現状の一覧画面（`/`）およびヘッダーには新規作成への導線が存在しない。ユーザーはURLを直接知っているか、手動でパスを入力しないと作成画面へ行けない。本設計はその導線を追加することを目的とする。

既存の作成画面（`src/routes/_protected/bookmarks/new/index.tsx`）は URL とタイトルを入力するフォームを持ち、すでに「一覧へ戻る」リンクを含む。本設計ではこの画面の中身を変更せず、導線の接続のみを行う。

## 変更箇所

### a. ヘッダー常設リンク — `src/routes/_protected.tsx`

レイアウトの `<nav>` 内（既存の「タグ」「設定」リンクと同じ箇所）に「＋新規ブックマーク」リンクを追加する。

- 既存の `Link` コンポーネントと同じインポート・パターンを使用。
- `to='/bookmarks/new'` で遷移。
- タグ・設定リンクと視覚的に並ぶよう配置。

### b. 一覧画面内の導線 — `src/routes/_protected/index.tsx`

`RouteComponent` の見出し「{user.name}のブックマーク一覧」のそば（またはその直下）に「新規作成」リンク/ボタンを配置する。

- `Link` で `to='/bookmarks/new'` へ遷移。
- 一覧（`BookmarkTable`）の上または見出し横に置き、目立つようにする。

### c. 戻る導線の確認・整備 — `src/routes/_protected/bookmarks/new/index.tsx`

既存の「一覧へ戻る」リンク（`to='/'`, `search={{ tagMode: 'and', sort: 'newest' }}`）を確認する。

- 動作変更はしない。
- 必要に応じて配置やスタイルを整備（可読性・アクセシビリティの観点からラベルが明確であることを確認）。

## データフロー

変更なし。導線は既存ルートへの `Link` によるクライアントサイド遷移のみ。Server Function、DB スキーマ、バリデーションスキーマの変更は一切行わない。

## 認証・エラーハンドリング

- 新規作成画面は `_protected` レイアウト配下にあり、`beforeLoad` でセッション確認・未認証時は `/sign-in` へリダイレクトされる。導線追加による認証周りの変更は不要。
- リンク遷移のため、追加のエラーハンドリングは不要。

## テスト・検証

- Vitest：純粋な UI リンク追加のため、既存テストへの影響なし。新規ユニットテストは追加しない。
- Playwright MCP で以下の3経路を確認：
  1. ヘッダーの「＋新規ブックマーク」→ 作成画面（`/bookmarks/new`）への遷移。
  2. 一覧画面内の「新規作成」→ 作成画面への遷移。
  3. 作成画面の「一覧へ戻る」→ 一覧画面（`/`）への遷移。
- アクセシビリティ：リンクに明確なラベルがあり、キーボード操作・フォーカス順が自然であることを確認。

## 範囲外（今回は実施しない）

- タイトル自動取得（URL入力時のページタイトル取得）。
- 作成画面でのタグ選択・新規作成。
- 作成画面でのメモ（note）入力（編集画面には既存）。
- 作成画面フォーム自体の構造変更。
- これらは別タスクとして MVP 設計に沿って実施する。
