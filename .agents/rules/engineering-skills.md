# Engineering Skills

The following skills are mandatory when their trigger conditions apply.

## Debugging

For bugs, test failures, build failures, performance issues, or unexpected
behavior:

- Use `systematic-debugging`.
- Identify the root cause before implementing a fix.

## Verification

Before claiming work is complete, fixed, correct, passing, or ready:

- Use `verification-before-completion`.
- Obtain fresh verification evidence.

## Code review

When receiving or acting on code review feedback:

- Use `receiving-code-review`.
- Verify the technical validity of the feedback before implementing it.
